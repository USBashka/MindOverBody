# Установка MOB

## Android: устанавливаемый APK

APK — отдельное приложение с локально упакованными интерфейсом, курсом и движком Rusterize. Для запуска не нужен браузер или подключение к сайту. Сборка, подпись и подключение Google Диска описаны в [ANDROID.md](ANDROID.md).

## Веб и PWA

Откройте [MOB](https://usbashka.github.io/MindOverBody/) в современном браузере. На Android в Chrome выберите меню → **Установить приложение** или **Добавить на главный экран**. На компьютере используйте значок установки в адресной строке Chrome/Edge. Название команды зависит от браузера.

Первый запуск требует интернета: приложение сохраняет интерфейс, уроки, библиотеку и движок карты. После завершения установки service worker приложение работает без сети. Google Диск требует интернета и отдельного разрешения пользователя. Новый выпуск устанавливается после закрытия вкладок со старой версией; несохранённая запись не перезагружается принудительно.

Для камеры используйте HTTPS или localhost. Браузер/Android попросит разрешение только при выборе фотографии. Произвольный HTTP-адрес в локальной сети не поддерживает установку PWA и часть браузерных функций.

## Данные

Дневник хранится в IndexedDB текущего браузера или в отдельном хранилище Android-приложения. PWA и APK имеют отдельные хранилища: переносите записи резервной копией MOB или Google Диском. Приватный режим, удаление данных сайта и удаление Android-приложения стирают его локальные записи. Используйте экспорт JSON или подключите Диск до удаления приложения.

## Локальная разработка

Требуются Node.js 22+ и npm. Готовые файлы Rusterize WASM находятся в `public/rusterize/`; изменение Rust-кода требует Rust stable с целью `wasm32-unknown-unknown`.

```sh
npm ci
npm test
npm run build
npm run serve
```

Откройте `http://127.0.0.1:4173`. Для проверки пути GitHub Pages:

```sh
npm run serve -- --base /MindOverBody/
```

Браузерные проверки:

```sh
npx playwright install chromium
npm run test:e2e
```

На машине с установленным Chromium можно передать `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium`. Сборка не требует сервера приложений, базы данных, секретов или авторизации в MOB.

## GitHub Pages

Workflow `Deploy MOB` запускает тесты, пересобирает Rust/WASM, проверяет браузер и публикует папку `dist/` через GitHub Pages. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**. Деплой разрешён только из `main`; pull request проходит проверки без публикации.

Все пути относительные. Сайт работает и на корневом домене, и по адресу `/MindOverBody/`. Service worker кеширует только статические файлы приложения; записи пользователя и ответы Google API не попадают в кеш сайта.
