# Проверка MOB 1.0

Проверено 17 октября 2026 года. Этот документ отделяет выполненные проверки от непроверенных интеграций.

## Веб и PWA

- 46 модульных тестов: 19 для хранилища и Somnio, 13 для Google Drive с имитацией API, 9 для Markdown, 5 для модели карты и статистики.
- Production-сборка обслуживалась по `/MindOverBody/`, как на GitHub Pages.
- Реальный Chromium: desktop 1440×1000 и мобильный экран 390×844, DPR 2, часовой пояс Europe/Samara.
- Создание, чтение, редактирование и удаление записей; первый тип дня; повторное открытие браузера; поиск и фильтры; все шесть типов тегов; восстановление черновика с новыми тегами.
- Рисунок, отмена штриха, сохранение; выбор файла, `capture=environment`, вставка изображения из буфера, подписи и изображения тегов. Физическая камера телефона не участвовала в этих браузерных тестах.
- Настоящий WASM Rusterize: открытие локации, перенос с сохранением координат после перезагрузки, масштаб, сброс карты, изображения, огоньки и персонажи.
- Курс: открытие урока, прогресс после перезагрузки; поиск справки; статистика; экспорт JSON с иллюстрациями и картой.
- Service worker: установка в подкаталог, перезагрузка без сети, создание записи без сети, офлайн-чтение курса. Автоматическое обновление не прерывает открытый редактор.
- Проверено отсутствие горизонтального переполнения, ошибок JavaScript и внешних запросов в обычных локальных сценариях.
- HTML в Markdown не исполняется, ссылки `javascript:` блокируются, удалённые изображения не загружаются.
- Два экземпляра IndexedDB в разных вкладках одновременно сохранили разные изменения из устаревших снимков: обе записи сохранены.

## Импорт Somnio

Предоставленный личный файл проверен только локально: **475 записей, 135 тегов, без предупреждений**. Повторный импорт добавляет **0** записей. Проверены даты, исходный текст, JSON-экспорт и повторное чтение резервной копии. В публичных исходниках и скриншотах личного дневника нет.

## Rusterize

`cargo fmt --check`, четыре Rust-теста и Clippy с `-D warnings` пройдены. Release-WASM включён в приложение. Отдельный браузерный тест проверяет реальные пиксели импортированного RGBA-изображения, pointer-события, клавиатуру, выход фокуса по Tab, движение персонажей, reduced motion, остановку кадров в покое, DPI/resize и освобождение ресурсов.

Карта использует Rust `Application` и Canvas display list Rusterize. Остальные разделы — HTML-интерфейс. Android исполняет эту карту через WASM в системном WebView; прямой JNI/Android Canvas-бэкенд не заявляется.

## Android

Подписанный release APK собирается для Android 8.0+ (minSdk 26, targetSdk 35), проходит Android lint и проверку `apksigner`. Release-сборка не разрешает WebView debugging. Ресурсы приложения, курс, библиотека и WASM упакованы внутрь APK; service worker в APK отключён. Постоянный приватный ключ хранится вне репозитория и передаётся владельцу отдельно.

Фактическая проверка на Android-эмуляторе будет зафиксирована ниже после завершения запуска. Компиляция APK не заменяет проверку на физических устройствах разных производителей.

## Google Drive и границы проверки

Проверены запросы API, скрытая папка приложения, отдельные снимки устройств, слияние изменений, отмена и смена аккаунта, устаревшие разрешения, ограниченный доступ, тайм-ауты, повреждённые ответы и повторное подключение. Веб и Android имеют отдельные OAuth-пути. Токен не сохраняется в JSON и локальном хранилище.

**Реальный вход и обмен с Google Drive не выполнены:** в сессии нет настроенного пользовательского Google Cloud проекта/OAuth-клиентов. Это необходимая внешняя настройка, описанная в [GOOGLE_DRIVE.md](GOOGLE_DRIVE.md) и [ANDROID.md](ANDROID.md). Не следует считать её выполненной по наличию кнопки или имитационных тестов.

Firefox, Safari/iOS, физическая камера Android, разнообразие WebView-провайдеров и Google Play Services на реальных устройствах требуют дополнительной проверки. Приложение не обеспечивает дополнительное сквозное шифрование резервных копий. JSON-импорт и облачные снимки ограничены 100 МиБ. Браузерный аварийный экспорт остаётся доступен и при большем размере; сохранение через системный диалог APK ограничено 64 МиБ на файл. Большие галереи требуют контроля размера и резервных копий.

## Повторить проверки

```sh
npm ci
npm test
npm run build
npx playwright install chromium
npm run test:e2e
cargo test --manifest-path native/Cargo.toml --locked
cargo clippy --manifest-path native/Cargo.toml --all-targets -- -D warnings
node native/check-web.mjs
npm run build:android
```

Для локального Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE`. Приватный Somnio-файл передаётся только через `SOMNIO_FIXTURE=/absolute/path.json`; он не нужен для CI. Снимки для документации используют отдельный встроенный демонстрационный дневник с вымышленными историями.
