# Данные и приватность MOB

MOB не имеет своего сервера, регистрации, аналитики, рекламы и удалённых шрифтов. Дневник, рисунки, фотографии, теги, позиции локаций и учебный прогресс сохраняются в IndexedDB текущего браузера или Android WebView. Текст незавершённой новой записи сохраняется в локальный черновик; изображения черновика остаются в памяти до сохранения записи.

Открытие веб-версии обращается к GitHub Pages за статическими файлами приложения. GitHub обрабатывает обычные сетевые данные посетителей по своей политике. Содержимое дневника при этом не отправляется. После первого успешного открытия service worker сохраняет приложение для работы без сети. APK содержит эти ресурсы внутри установки и не зависит от GitHub Pages.

## Подключение Google Диска

Это необязательное действие в настройках. Подключение открывает Google OAuth в браузере либо системное разрешение Google Play Services на Android. Приложение запрашивает `drive.appdata` — доступ к скрытой папке собственных данных MOB, а не ко всему Диску.

По нажатию «Синхронизировать» записи, изображения, теги, позиции карты, сохранённые версии и учебный прогресс отправляются напрямую в Google Drive. У MOB нет промежуточного сервера. Каждое устройство хранит отдельный снимок; синхронизация читает доступные снимки и объединяет изменения. Токен доступа хранится только в оперативной памяти и не включается в резервные копии. Настройки подключения остаются на устройстве.

Снимок не имеет дополнительного сквозного шифрования средствами MOB. Он защищён механизмами аккаунта и транспорта Google. Подключайте Drive только если хотите хранить там эти данные. Отключение Drive не удаляет уже существующие копии. Их можно удалить в управлении приложениями Google Drive.

## Импорт и экспорт

Somnio JSON обрабатывается локально. Предоставленный для разработки личный пример не включён в приложение, исходный код или скриншоты. Демонстрационный дневник содержит только вымышленные записи и не сохраняется в основной дневник.

Резервная копия JSON содержит весь дневник, включая изображения и архив версий. Markdown и CSV предназначены для просмотра вне MOB. Эти файлы не зашифрованы: выбирайте безопасное место хранения. Поддерживаемый предел входного JSON — 100 МиБ; очень большие библиотеки изображений требуют внимания к объёму резервной копии.

Markdown не исполняет HTML и JavaScript. Удалённые изображения в Markdown не загружаются, чтобы внешние сайты не получали запросы при чтении личной записи. Иллюстрации импортируются с устройства и сохраняются в локальном формате. Внешние ссылки открываются только по нажатию пользователя.

## Сохранность

- Очистка данных сайта, приватный режим, смена браузерного профиля или удаление APK могут удалить локальные данные.
- Установка PWA и запрос постоянного хранения помогают, но резервные копии остаются необходимыми.
- APK и браузер имеют разные локальные хранилища. Для переноса используйте JSON или настройте Google Drive на обоих устройствах.
- Удалённые записи оставляют отметку удаления для синхронизации. Старые версии могут сохраняться в архиве резервной копии.
- Данные на устройстве не зашифрованы отдельным паролем MOB. Используйте системную блокировку и шифрование устройства.
